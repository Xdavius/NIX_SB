# Consommation depuis GLF-OS

Aucune modification du code GLF-OS n’est incluse ni autorisée dans cette refonte.
NIX_SB expose des paquets ordinaires via `callPackage`.

Consulter [usage.md](usage.md) pour l’API et [MIGRATION-GLF.md](MIGRATION-GLF.md)
pour les changements par rapport au prototype. Les exemples sont documentaires.
L’ancien patch d’intégration et le module NixOS de production ont été retirés.
